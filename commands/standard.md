# STANDARD Mode

Use STANDARD mode for the current task.

1. Inspect the existing subsystem.
2. State concise acceptance criteria and assumptions.
3. Declare a small complexity budget.
4. Create a short execution plan.
5. Implement in coherent increments.
6. Add/update meaningful tests.
7. Run the simplification gate.
8. Verify the final behavior.

Escalate to DEEP if high-risk boundaries emerge.
