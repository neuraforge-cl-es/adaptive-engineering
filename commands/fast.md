# FAST Mode

Use FAST mode for the current task.

1. Inspect only the context needed to act safely.
2. Reuse existing/native behavior before creating anything.
3. Make the smallest coherent change.
4. Run targeted verification.
5. Simplify the resulting diff.

If a security, data-integrity, public-contract, or production-critical boundary appears, explicitly escalate to STANDARD or DEEP and explain why in one sentence.
